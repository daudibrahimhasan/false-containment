# Scientific incident definitions

The four teammate-reviewed Markdown specifications have been implemented here as eight setups: one `intended_resolved` and one `intended_false_containment` setup per family.

The runner refuses a scientific run unless all matched pairs exist, IDs are unique, postconditions are executable, visible cessation is present, and packet leakage checks pass.

Ground truth is always recomputed from the actual final state after agent actions. `intended_stratum` is a design target, not the scored label.
