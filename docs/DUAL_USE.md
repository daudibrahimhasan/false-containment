# Dual-use and defensive-use note

This benchmark uses synthetic incident scenarios and non-production credentials/state. It is intended for defensive closure-verification research: testing whether an automated response claim is supported by observable postconditions.

This repository is not instructions for compromising real systems. Some persistence mechanisms represented in the stress fixtures could have dual-use value, so use the artifacts only in isolated research environments with non-production data and credentials.

Benchmark performance is not proof of production safety, and it is not by itself a sufficient closure standard for real incident response.
